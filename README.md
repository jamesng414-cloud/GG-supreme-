# GG Supreme V12

保留原站深色界面的 TOTO 历史分析工具。每次生成一组6个不重复的1–49号码，支持核心历史评分、纯随机、旧版频率加权和区间均衡。任何历史评分都不会提高公平随机开奖中某一指定组合的中奖概率。

V12 的逐期回测只读取目标期之前的数据，与生成时使用相同的历史窗口；固定种子随机对照便于复查，并列出公平抽样的理论值。回测不会写入候选记录，事后回测不能作为真实预测成绩。

原有浏览器存储键保持不变：

| 数据 | 存储键 |
| --- | --- |
| 手动补录 | `gg-supreme-v10-manual-draws` |
| 生成记录 | `gg-supreme-v6-candidates` |
| 候选追踪 | `gg-supreme-v7-tracker` |
| 新增的自动数据离线缓存 | `gg-supreme-v12-automatic-draws` |

同一网址、同一浏览器中的旧记录会继续使用。完整备份包含自动历史、手动补录、生成和追踪记录；兼容旧版 V10.1/V11/V12 备份。恢复采用合并去重，同期期号冲突保留本机版本，取消恢复或格式验证失败不会写入。保存时不再按30/500条截断历史，仅限制页面显示数量。

共享 CSV 由 GitHub 仓库写入权限控制。本页没有独立的服务器管理员登录；网页上的补录、恢复和删除只影响当前浏览器。对奖仅比较6个主号码。时间按新加坡日期判断；缺少官方开奖时间时，同日记录显示命中数但不计成绩，避免错误声称其为开奖前预测。

`toto_prizes.csv` 包含完整的原始历史，页面只分析2014-10-01起有效的6/49记录。定时工作流通过 `scripts/update_toto.py` 添加有效新期号，保留已有行、缺值旧行和本地冲突版本。

运行验证：

```sh
node --test tests/v12.test.cjs
python3 -m unittest discover -s tests -p 'test_*.py'
```
